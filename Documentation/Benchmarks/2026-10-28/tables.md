# Editor 측정 통계표

같은 조건으로 5회씩 실행한 결과를 모았습니다. 인원은 진영별 수이며, 생존 수는 전투가 끝났을 때 두 진영에 남은 유닛의 합계입니다. 시간 단위는 한 스텝당 밀리초(ms)로 작을수록 좋습니다.

p50은 중앙값, p95는 표본을 빠른 순서로 정렬했을 때 95% 지점의 값입니다. 각 실행에서 통계를 먼저 구한 뒤, 그 값 5개의 중앙값을 아래 표에 적었습니다. ‘평균’ 열도 실행별 평균 5개의 중앙값이며, 종료 스텝과 생존 수의 범위는 5회 실행의 최솟값–최댓값입니다.

물리 계산, 공격 조회, 공통 로직, 위치 읽기, mesh 갱신을 구분해 기록했습니다. 서로 다른 통계를 더해 전체 시간을 계산할 수는 없으며, mesh 갱신에는 GPU 렌더링 시간이 포함되지 않습니다. 자세한 조건은 [측정 방법](../README.md)을 참고하세요.
